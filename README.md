# 🎵 AppMusica

Aplicación móvil nativa para Android enfocada en la reproducción y gestión de música. Diseñada con una interfaz moderna y fluida siguiendo las guías de Material Design.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Kotlin
* **IDE:** Android Studio
* **Min SDK:** 24+ (Android 7.0 Nougat o superior)
* **Control de Versiones:** Git & GitHub

---

## 🚀 Características Principales

* 🎶 Reproducción de listas y pistas de audio.
* 📱 Interfaz intuitiva y adaptada a dispositivos móviles.
* ⚡ Rendimiento optimizado utilizando las mejores prácticas de desarrollo Android.
